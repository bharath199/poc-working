01 / The problem

Thousands of tiny bumps. One bad one is enough.

Bumps keep getting smaller and denser, so bad ones get harder to catch. Most inspection machines are imported, just as India's packaging plants are starting up.

02 / First tool

Find the defects. Measure every bump.

Light sweeps across the part. The tool flags visible defects and measures the height of every bump in 3D. In development, with specifications set together with the plants that will use it.
