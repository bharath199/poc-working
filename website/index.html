3D Automated Optical Inspection

3D AOI for solder-joint inspection, sized for mid-market EMS

We're developing a new-build 3D AOI system aimed at the same accuracy class as established vendors — Koh Young, CyberOptics, TRI, Mirtec, Saki — built on off-the-shelf optics, cameras, and projection hardware instead of specialized proprietary components.

Problem

The AOI gap in Indian EMS

Established 3D AOI systems cost ₹15–80 lakh. That's a workable capital expense for large Tier-1 EMS and OEMs, but it prices out most MSME and mid-market shops.

The usual workaround is a used or desktop 3D AOI unit at ₹10–15 lakh, which trades away accuracy and support. For general SMT work that's often tolerable. For tight-tolerance work — automotive electronics under IATF 16949 — it's a real risk: marginal AOI coverage on joints where a miss has downstream cost.

Result: mid-market and MSME EMS shops in the Chennai-Bengaluru cluster either skip 3D AOI or run it on equipment that wasn't built for the tolerance band they're actually inspecting to.

₹15–80L Established 3D AOI vendors (Koh Young, CyberOptics, TRI, Mirtec, Saki)
₹10–15L Used / desktop 3D AOI — weaker accuracy and support
IATF 16949 The tolerance standard that makes the gap costly for automotive-Tier work

Approach

Same accuracy class, different build

We're building a new 3D AOI system aimed at the accuracy class of the established players, using off-the-shelf optics, cameras, and projection components instead of the specialized proprietary hardware that drives their cost. The target is a system priced for mid-market and MSME EMS budgets without cutting into inspection accuracy.

Off-the-shelf optical hardware

Commercial-grade optics, cameras, and a projector in place of vendor-proprietary sensor modules — the same measurement principle, a different cost structure.

Accuracy class as the design target

The system is being designed and bench-validated against the accuracy class established vendors operate in, not a relaxed spec for a lower price point.

Built for the tolerance band that matters

Development is aimed squarely at the tight-tolerance solder-joint inspection that automotive-Tier EMS work requires, not general-purpose SMT checks.
